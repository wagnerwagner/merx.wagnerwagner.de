Title: Stripe card element

----

Headline:

----

Intro: Use a plain card field from Stripe instead of the Payment Element, next to a payment method of your own, such as invoice.

----

Text:

The [Stripe guide](/guide/payment-gateways/stripe) uses the Payment Element, which shows the payment methods of your Stripe account in one frame. The card element is only the card number, expiry date and CVC. Your checkout decides which payment methods it offers and how they look.

This recipe offers card and [invoice](/guide/payment-gateways/invoice), so invoice has to be switched on:

```php title="/site/config/config.php"
<?php

return [
  'wagnerwagner.merx.gateways' => [
    'invoice' => true,
  ],
];
```

## The checkout form

Each radio button sends the name of a gateway. The card element mounts into the empty `div`.

```php title="/site/templates/checkout.php"
<?php
$stripePublishableKey = option('wagnerwagner.merx.production') === true
  ? option('wagnerwagner.merx.stripe.live.publishable_key')
  : option('wagnerwagner.merx.stripe.test.publishable_key');
?>
<script src="https://js.stripe.com/endive/stripe.js"></script>

<form id="checkout-form" action="<?= url('api/shop/checkout') ?>" method="post" data-stripe-publishable-key="<?= $stripePublishableKey ?>">
  <!-- Other form fields -->
  <label><input type="radio" name="payment_gateway" value="stripe" checked> Card</label>
  <div id="card-element"></div>
  <label><input type="radio" name="payment_gateway" value="invoice"> Invoice</label>
  <button>Submit order</button>
</form>
```

The card field is only needed while card is chosen:

```css title="/assets/css/checkout.css"
#checkout-form:has([value="invoice"]:checked) #card-element {
  display: none;
}
```

## Pay by card

The client secret is fetched when the customer submits the form, not when the page loads. The payment intent then always holds the current cart total, and invoice customers never create one. Fetch it before the checkout request: Merx adds the payment intent of the visitor’s session to the order there.

```js title="/assets/js/checkout.js"
const checkoutForm = document.getElementById('checkout-form');
const stripe = Stripe(checkoutForm.dataset.stripePublishableKey);
const card = stripe.elements({ locale: document.documentElement.lang }).create('card', {
  // The billing address is part of your own form
  hidePostalCode: true,
});
card.mount('#card-element');

checkoutForm.addEventListener('submit', async (event) => {
  event.preventDefault();
  const formData = new FormData(checkoutForm);
  const payByCard = formData.get('payment_gateway') === 'stripe';

  let clientSecret;
  if (payByCard) {
    ({ clientSecret } = await (await fetch('/api/shop/stripe-client-secret')).json());
  }

  const response = await fetch(checkoutForm.action, {
    method: 'post',
    body: formData,
    headers: { 'Accept': 'application/json' },
  });
  const json = await response.json();

  if (json.status !== 'redirect') {
    // Show the validation errors, see “Validate checkout”
    return;
  }

  if (payByCard) {
    const { error } = await stripe.confirmCardPayment(clientSecret, {
      payment_method: { card },
    });
    if (error) {
      // E.g. a declined card. The customer can correct it and submit again.
      alert(error.message);
      return;
    }
  }

  window.location.href = json.redirectUrl;
});
```

[Validate checkout](/guide/getting-started/validate-checkout) shows how to display the validation errors next to their fields.

Stripe asks for 3-D Secure in a dialog of its own when the bank requires it, so `confirmCardPayment()` returns only once the payment is settled. The customer then goes to the order page, which completes the order as described in the [Stripe guide](/guide/payment-gateways/stripe#submit-the-payment-to-stripe).

## Loading Stripe.js only when needed

Invoice customers don’t need Stripe.js. To keep it off their page, add the `script` element from JavaScript once card is chosen, and create the card element after it has loaded. The [starter kit](https://github.com/wagnerwagner/merx-starterkit/blob/main/assets/js/templates/checkout.js) does it this way.
