Title: Showing the cart

----

Headline: 

----

Intro: Learn how to show the customer’s cart using JavaScript.

----

Text:

We recommend using JavaScript and the API to show the cart to the customer. This makes it possible to cache all pages server-side and load the cart asynchronously.

Let’s define a [custom element](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements) for it. It has a `fetchCart()` function, which gets the cart data from the API endpoint, and a `render()` function, which renders the cart as a list.

```js title="script.js"
/** Makes a value safe to put into HTML */
const esc = (value) => String(value ?? '').replace(
  /[&<>"']/g,
  (character) => `&#${character.charCodeAt(0)};`,
);

customElements.define('my-cart', class extends HTMLElement {
  /** @see https://merx.wagnerwagner.de/reference/api/models/cart */
  data = null;

  endpoint = '/api/shop/cart';

  async fetchCart() {
    const response = await fetch(this.endpoint, {
      headers: {
        'X-Language': document.documentElement.lang,
      },
    });
    const json = await response.json();
    this.data = json.data;
  }

  async connectedCallback() {
    await this.fetchCart();
    this.render();
  }

  render() {
    const items = this.data?.products?.items ?? [];

    this.innerHTML = `
      <h2>Cart</h2>
      ${items.length === 0 ? '<p>Empty cart</p>' : `
        <ul>
          ${items.map(item => `
            <li>
              <strong>${esc(item.title)}</strong><br>
              Price: ${esc(item.price?.price ?? 'On request')}
            </li>
          `).join('')}
        </ul>
        <p>Total: ${esc(this.data.total?.price)}</p>
        ${this.data.checkout ? `<a href="${esc(this.data.checkout.url)}">${esc(this.data.checkout.title)}</a>` : ''}
      `}
    `;
  }
});
```

Add the `<my-cart>` element to the header of your page — or wherever you want to show the cart.

> [!IMPORTANT]
> `innerHTML` runs whatever HTML it is given. Pass every value from the API through `esc()`, also the ones that look harmless: a title is typed by an editor, and an item’s `data` by the customer.

A product without a price returns `null` instead of a price object. `checkout` is `null` until a page with the checkout template exists, which is the [next step](/guide/getting-started/create-checkout), so the link is only rendered once there is one. To check which other fields are available, see the [Cart model reference](/reference/api/models/cart).
