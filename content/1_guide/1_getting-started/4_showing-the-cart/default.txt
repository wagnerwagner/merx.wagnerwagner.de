Title: Showing the cart

----

Headline: 

----

Intro: Learn how to show the customer’s cart using JavaScript.

----

Text:

We recommend using JavaScript and the API to show the cart to the customer. This makes it possible to cache all pages server-side and load the cart asynchronously.

For this example we define a [custom element](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements). There is a `getCart()` function, which gets the cart data from the API endpoint. And a `render()` function, which renders the cart as a list.

<code caption="script.js">
```js
customElements.define('my-cart', class extends HTMLElement {
  /** @see https://merx.wagnerwagner.de/reference/api/models/cart */
  data = null;

  endpoint = '/api/shop/cart';

  async fetchCart() {
    const response = await fetch(this.endpoint, {
      headers: {
        'X-Language': document.documentElement.lang,
      },
    });
    const json = await response.json();
    this.data = json.data;
  }

  async connectedCallback() {
    await this.fetchCart();
    this.render();
  }

  render() {
    const items = this.data?.products?.items ?? [];

    this.innerHTML = `
      <h2>Cart</h2>
      ${items.length === 0 ? '<p>Empty cart</p>' : `
        <ul>
          ${items.map(item => `
            <li>
              <strong>${item.title}</strong><br>
              Price: ${item.price?.price ?? 'On request'}
            </li>
          `).join('')}
        </ul>
        <p>Total: ${this.data.total?.price ?? ''}</p>
      `}
    `;
  }
});
```
</code>

Add the `<my-cart>` element to the header of your page.

A product without a price returns `null` instead of a price object, which is what `isFromPrice` on the cart tells you about. To check which other fields are available, see the [Cart model reference](/reference/api/models/cart).
