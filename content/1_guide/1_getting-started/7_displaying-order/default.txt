Title: Displaying order

----

Headline: 

----

Intro: Learn how to show the order information including cart and customer data.

----

Text:

During the checkout process, a new [`OrderPage`](/reference/classes/order-page) is created as a child of [`$site->ordersPage()`](/reference/options/site-methods/orders-page) with a random id.

The order number is created automatically. By default it’s an incrementing number. You can replace it with a numbering of your own through the [`orderNumber`](/reference/options/config-options/order-number) option.

## Create template

```php title="/site/templates/order.php"
<?php /** @var Wagnerwagner\Merx\OrderPage $page */ ?>

<h1>Order #<?= $page->orderNumber() ?></h1>

<p>Name: <?= $page->given_name()->escape() ?> <?= $page->family_name()->escape() ?></p>

<?php snippet('cart', ['cart' => $page->cart()]) ?>
```

> [!CAUTION]
> Always use [`$field->escape()`](https://getkirby.com/docs/reference/templates/field-methods/escape) for fields with user generated content to prevent [XSS attacks](https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/XSS).

## Cart snippet

To display the summary of the items ordered, you can create a new cart [snippet](https://getkirby.com/docs/guide/templates/snippets).

```php title="/site/snippets/cart.php"
<?php /** @var \Wagnerwagner\Merx\ProductList $cart */ ?>
<table>
  <thead>
    <tr>
      <th>Item</th>
      <th>Price per item</th>
      <th>Quantity</th>
      <th>Total</th>
    </tr>
  </thead>
  <tbody>
    <?php foreach ($cart as $item): ?>
      <?php /** @var Wagnerwagner\Merx\ListItem $item */ ?>
      <tr>
        <td><?= html($item->title()) ?></td>
        <td><?= $item->price() ?></td>
        <td><?= $item->quantity() ?></td>
        <td><?= $item->total() ?></td>
      </tr>
    <?php endforeach ?>
  </tbody>
  <tfoot>
    <?php foreach ($cart->taxRates() as $tax): ?>
      <tr>
        <th colspan="3">incl. <?= $tax->rate() ?> VAT</th>
        <td><?= $tax ?></td>
      </tr>
    <?php endforeach ?>
    <tr>
      <th colspan="3">Total</th>
      <td><?= $cart->total()->toString('price') ?></td>
    </tr>
  </tfoot>
</table>
```

[`taxRates()`](/reference/classes/cart/tax-rates) gives one line per tax rate, which is what an invoice needs when the order mixes rates — see [Taxes](/guide/configuration/taxes).

## Your own order model

By default an order page uses [`Wagnerwagner\Merx\OrderPage`](/reference/classes/order-page). Extend it in `/site/models/order.php` to give your templates methods of their own — Kirby derives the class name from the template file name, so it has to be `OrderPage`.

```php title="/site/models/order.php"
<?php

class OrderPage extends \Wagnerwagner\Merx\OrderPage
{
  public function fullName(): string
  {
    return trim($this->given_name() . ' ' . $this->family_name());
  }
}
```

Kirby loads models after plugins, so yours wins without any registration.

\----

The order page is a confirmation to your customer that the order was successful. Additionally, you might [send a confirmation email](/guide/getting-started/sending-emails) to your customer.
