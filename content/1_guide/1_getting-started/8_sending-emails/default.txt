Title: Sending emails

----

Headline: 

----

Intro: Learn how to use hooks to send confirmation mails to the customer.

----

Text:

Merx comes with several [hooks](/reference/options/hooks) that allow you to hook into processes.


Use the [`createOrder:after`](/reference/options/hooks/create-order-after) hook to send a mail to the customer to inform about the succeeded order.

```php title="/site/config/config.php"
<?php

return [
  'hooks' => [
    'wagnerwagner.merx.createOrder:after' => function (\Wagnerwagner\Merx\OrderPage $orderPage) {
      $name = $orderPage->given_name() . ' ' . $orderPage->family_name();
      kirby()->email([
        'from' => 'info@shop.test',
        'fromName' => $orderPage->site()->title(),
        'to' => [(string)$orderPage->email() => $name],
        'subject' => 'Thanks for your order!',
        'body' => 'Dear ' . $name . ', thank you for your order of ' . $orderPage->total(),
      ]);
    },
  ],
];
```

The hook runs for every order, paid or not: an invoice or SEPA Direct Debit order is still waiting for its payment. Check [`$orderPage->isPaid()`](/reference/classes/order-page/is-paid) before the mail says the order is paid.

Read [Kirby’s guide about emails](https://getkirby.com/docs/guide/emails) to learn more about sending mails.

## Best practices

### Use email presets

It’s recommended to use [mail presets](https://getkirby.com/docs/guide/emails#presets). This has the advantage that you can define the sender email address and a mail template globally in the config file.

```php title="/site/config/config.php"
<?php
return [
  'email' => [
    'presets' => [
      'createOrder' => [
        'from' => 'info@shop.test',
        'template' => 'create-order',
      ],
    ],
  ],
  'hooks' => [
    'wagnerwagner.merx.createOrder:after' => function (\Wagnerwagner\Merx\OrderPage $orderPage) {
      kirby()->email('createOrder', [
        'to' => (string)$orderPage->email(),
        'fromName' => $orderPage->site()->title(),
        'subject' => 'Thanks for your order!',
        'data' => [
          'orderPage' => $orderPage,
        ],
      ]);
    },
  ],
];
```

```php title="/site/templates/emails/create-order.php"
<?php /** @var \Wagnerwagner\Merx\OrderPage $orderPage */ ?>
Dear <?= $orderPage->given_name() ?> <?= $orderPage->family_name() ?>, thank you for your order of <?= $orderPage->total() ?>
```

> [!CAUTION]
> When you create [html emails](https://getkirby.com/docs/guide/emails#formats__html-plain-text), always use [`$field->escape()`](https://getkirby.com/docs/reference/templates/field-methods/escape) for fields with user generated content to prevent [XSS attacks](https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/XSS).
