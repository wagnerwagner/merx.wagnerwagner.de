Title: Payment gateways

----

Headline: 

----

Intro: Merx comes with Stripe and PayPal built in.

----

Text:

Payment gateway | Provider | Keyword
| ---- | ---- | ---- |
[PayPal Payments](/guide/payment-gateways/paypal) | (link: https://developer.paypal.com/api/orders/v2 text: PayPal) | `paypal`
[Stripe](/guide/payment-gateways/stripe)<br>Includes **all** available Stripe Payment methods | [Stripe](https://stripe.com/de/payments/payment-methods) | `stripe`

If you want to use another payment provider read the (link: /guide/payment-gateways/custom-payment-gateway text: Custom Payment Gateways) guide to learn how to create your own custom payment gateway. For orders paid outside your shop, such as on invoice, switch on a gateway that takes no payment: see [Invoice](/guide/payment-gateways/invoice).

A built-in gateway you don’t use is switched off with the [`gateways`](/reference/options/config-options/gateways) option. A checkout that still sends it is refused, the same as one that sends an unknown gateway.

```php title="/site/config/config.php"
<?php

return [
  'wagnerwagner.merx.gateways' => [
    'paypal' => false,
  ],
];
```

Learn how to connect your online shop with Stripe and/or PayPal by [setting up the secret keys](/guide/configuration/stripe-paypal-secrets). If you aren’t sure which payment gateway to use, we recommend Stripe. Learn how to **[set up Stripe](/guide/payment-gateways/stripe)**.
