Title: Merx 2

----

Headline: More shop. Just as simple.

----

Intro: Merx 2 is the new major version of Merx, built for Kirby 5. Prices in any currency, tax rates per product and country, a JSON API that keeps your pages cacheable, and every Stripe payment method in one integration. It’s a toolset, not a framework — if you know Kirby, you know Merx.

More:

- API responses in the visitor’s language, via the `X-Language` header
- Your own fields in every API response, with (link: page://qez0bnp1cqofknjo text: custom models)
- A shop settings tab for the Panel, with a shop-wide `maxQuantity`
- A log of errors, rejected webhooks and every order view
- Kirby 5.5 and PHP 8.2 to 8.5
